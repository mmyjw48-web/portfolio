# تشغيل الموقع لأول مرة (مرة واحدة فقط)

هذه الخطوات تُنفَّذ مرة واحدة لنشر الموقع. تحتاج حوالي 20 دقيقة. بعدها كل التعديلات تتم من لوحة التحكم.

> **قاعدة أمان:** الموقع يحتاج مفتاحًا واحدًا فقط من Supabase وهو **anon / publishable**. لا تنسخ أبدًا المفتاح المسمّى **service_role** أو **secret** ولا تضعه في Vercel ولا ترسله لأحد.

---

## الجزء الأول: Supabase (قاعدة البيانات وتسجيل الدخول والصور)

### 1) إنشاء المشروع
1. ادخل [supabase.com/dashboard](https://supabase.com/dashboard) ← **New project**.
2. الاسم: `portfolio`. المنطقة (Region): **Southeast Asia (Singapore)** لأنها الأقرب لإندونيسيا.
3. اكتب كلمة مرور لقاعدة البيانات واحفظها في مكان آمن (الموقع لا يحتاجها، لكنها مهمة لك).
4. اضغط **Create new project** وانتظر دقيقة حتى يجهز.

### 2) إنشاء الجداول
1. من القائمة الجانبية: **SQL Editor** ← **New query**.
2. افتح الملف `supabase/schema.sql` من المستودع على GitHub، انسخ كل محتواه، الصقه، ثم اضغط **Run**. يجب أن تظهر رسالة **Success**.
3. افتح **New query** جديد، والصق محتوى `supabase/seed.sql` (المحتوى الأولي: مشاريعك وخبراتك وشهاداتك)، ثم **Run**.

> تشغيل الملفين مرة ثانية آمن: لا يحذف شيئًا ولا يكتب فوق تعديلاتك.

### 3) حساب المدير (حسابك أنت فقط)
1. **Authentication** ← **Sign In / Providers**: تأكد أن **Email** مفعّل، ثم **أطفئ** خيار **Allow new users to sign up** حتى لا يستطيع أحد إنشاء حساب.
2. **Authentication** ← **Users** ← **Add user** ← **Create new user**:
   - Email: `mmyjw48@gmail.com`
   - Password: كلمة مرور قوية تختارها أنت (12 حرفًا على الأقل، فيها أحرف وأرقام ورموز). لا ترسلها لأحد.
   - فعّل **Auto Confirm User**.
3. هذا البريد مسجّل مسبقًا كمدير داخل قاعدة البيانات، فلا تحتاج أي خطوة إضافية.

### 4) نسخ المفتاحين
من **Project Settings** ← **API** (أو **Data API** و **API Keys**) انسخ:
- **Project URL** (يبدأ بـ `https://` وينتهي بـ `.supabase.co`)
- مفتاح **anon public** أو **publishable** (يبدأ بـ `eyJ` أو `sb_publishable_`)

## الجزء الثاني: Vercel (استضافة الموقع)

1. ادخل [vercel.com/new](https://vercel.com/new) ← اختر المستودع **mmyjw48-web/portfolio** ← **Import**.
2. **Project Name**: هذا الاسم يصبح رابط موقعك. مثال: `mohammed-mijo` ← يصبح الموقع `https://mohammed-mijo.vercel.app`.
3. افتح **Environment Variables** وأضف أربعة متغيرات:

| Name | Value |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | الـ Project URL من الخطوة 4 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | مفتاح anon / publishable من الخطوة 4 |
| `NEXT_PUBLIC_SITE_URL` | رابط موقعك، مثل `https://mohammed-mijo.vercel.app` |
| `CRON_SECRET` | أي نص عشوائي طويل (مثلًا 40 حرفًا ورقمًا مختلطة) |

4. اضغط **Deploy** وانتظر حتى تظهر **Congratulations**.

> إن كان الاسم الذي اخترته محجوزًا، سيعطيك Vercel رابطًا مختلفًا. انسخ الرابط الحقيقي من صفحة المشروع، وعدّل `NEXT_PUBLIC_SITE_URL` في **Settings ← Environment Variables** ثم **Deployments ← Redeploy**.

---

## الجزء الثالث: ربط الاثنين

ارجع إلى Supabase ← **Authentication** ← **URL Configuration**:
- **Site URL**: رابط موقعك، مثل `https://mohammed-mijo.vercel.app`
- **Redirect URLs** ← **Add URL**: `https://mohammed-mijo.vercel.app/admin/auth/callback`

هذا ضروري لرابط «نسيت كلمة المرور».

---

## الجزء الرابع: التجربة

1. افتح رابط موقعك: يجب أن يظهر بالإنجليزية، ويمكنك التبديل إلى العربية والإندونيسية من أعلى الصفحة.
2. افتح `/admin` (مثل `https://mohammed-mijo.vercel.app/admin`) وسجّل الدخول بالبريد وكلمة المرور.
3. غيّر أي شيء صغير (مثل وصف مشروع) ← **حفظ** ← افتح الموقع في نافذة جديدة. يجب أن ترى التعديل خلال ثوانٍ، دون أي نشر جديد.
4. أرسل رسالة تجريبية من نموذج التواصل في الموقع، وتأكد أنها ظهرت في **الرسائل** داخل لوحة التحكم.

إن نجحت الخطوات الأربع فالموقع جاهز.

## إن واجهت مشكلة

| المشكلة | الحل |
| --- | --- |
| لوحة التحكم تقول «لم يُربط الموقع بقاعدة البيانات بعد» | تأكد من أسماء المتغيرات في Vercel حرفًا بحرف، ثم Redeploy |
| «البريد أو كلمة المرور غير صحيحة» | من Supabase ← Users تأكد أن المستخدم موجود ومؤكَّد (Confirmed)، أو استخدم «نسيت كلمة المرور» |
| «هذا الحساب ليس حساب المدير» | سجّلت ببريد غير `mmyjw48@gmail.com`. سجّل الخروج وادخل بالبريد الصحيح |
| رابط «نسيت كلمة المرور» يفتح صفحة خطأ | راجع الجزء الثالث (Site URL و Redirect URLs) |
| الموقع يظهر لكن بدون تعديلاتك | تأكد أنك ضغطت «حفظ» وأن العنصر «منشور» و«ظاهر» |
| Supabase أرسل إيميلًا أن المشروع سيتوقف | الموقع يرسل إشارة يومية تمنع ذلك. إن توقف فعلًا، ادخل Supabase واضغط **Restore** |
